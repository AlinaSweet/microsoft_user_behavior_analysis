## 当前最重要的选择

先沿用已经搭好的 Dask + Pandas + PyArrow，完成分块清洗和 Parquet；再用简单统计特征训练逻辑回归、XGBoost、LightGBM。序列数据正确、评估可信后再做 DIN；DIEN、BST 作为扩展实验。此顺序是本项目的实施建议，效果由未来实验验证。

当前数据没有曝光和金额字段，不能据此计算真正 CTR 或金额型 RFM。数据只到小时，同一小时的多条行为没有可靠的真实先后顺序。相关处理边界在特征和实验方案中写明。
