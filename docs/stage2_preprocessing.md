# 第二阶段编码、变换与验证

## 输入与训练边界

前置为已验收的[用户商品对标签与分组筛选](feature_validation.md)。训练、验证、测试分别为
2025-11-25、12-02、12-09，标签窗口均为随后7天且互不重叠。
原439标量全部保留，207标量进入固定LR预实验；未来标签与三键不进入矩阵。

## 高维类别Target Encoding

user_preferred_category_7d采用按用户分组的5折OOF。某训练用户的编码使用完全排除其所在折的
类别正例数、样本数和全局先验，平滑参数50，避免本人或同用户其他候选标签泄漏。
公式为(类别正例数＋50×匹配先验)/(类别样本数＋50)，未知类目回退同一训练先验。
再用训练OOF的均值/标准差缩放；验证和测试使用冻结全训练映射。

这不是时间折外编码：历史不足以在首训练截点前取得成熟7天标签。
训练内部用用户OOF，完整时间外验证另在后两个截点进行；编码最早可用于12月2日推理。
没有调用验证、测试标签拟合映射、筛选规则、缩放器或缺失处理。

## 稀疏类别预嵌入

偏好类目、RF代理群与生命周期三类字段使用冻结训练词表及各自未知桶，构成稀疏one-hot。
仅训练特征拟合8维TruncatedSVD，不读标签；保存分量、训练投影均值和尺度。
它为后续模型提供预先压缩的类别输入，与用户商品交互SVD不同，不冒充监督深度模型的Embedding层。
任一类别未知时，高级增量实验回退对应基础业务模型，另报覆盖内外结果。

## 实际输出与评估

四截点完整矩阵259列，共4,426,649行；三键、原始TE值与预嵌入覆盖标志存同序侧表。
每片矩阵、键表和源片均有SHA-256。全部矩阵逐行重建误差0，全部验证/测试概率直接用保存系数重放误差0。
当前字典保留445源定义，另列9表示及259列映射，不混算数量。

旧六组LR结果保留为第一轮；新增六组TE/类别预嵌入与旧basic/business两个冻结参考组成固定8组对照。
每组使用相同全量训练行、5轮固定SGD逻辑回归；先冻结验证AP选择，再计算测试结果。
低/高活跃、新近观测用户、SVD/共现/类别预嵌入覆盖内外分别报告；AUC增量区间按用户成簇bootstrap。
组内相关性图为最多12个代表字段，完整所选数值相关矩阵CSV另存，高级组图仅计算覆盖内样本；互信息估计与剔除原因可逐字段查。

效果变化较小且不一致；旧OHE序列组验证AP仍略高于本轮TE序列组，不能宣称TE全面提升。
验证/测试用于最终评估；不依据本次测试结果继续挑字段或调阈值。
