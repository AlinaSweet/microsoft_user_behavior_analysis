## 每完成一个小任务的验收顺序

1. 逐项对照 PDF 任务和阶段交付清单，检查真实产物与执行结果。
2. 保存输入指纹、配置、代码版本、计数/指标、资源观察和失败记录。
3. 第一阶段复核已有工程与研究成果；第二阶段起，每个小任务后复核上一完整阶段，关联影响也必须回归。
4. 审阅代码差异，运行编码规范、类型、既有测试及路径/数据文件管理检查。
5. feature 分支 CI 通过后，更新台账与复核记录，按 feature → dev → main 同步。
6. 缺失的数据、授权或外部展示行为单独登记，有条件推进的工作继续。
