## 图表适配说明

- 没有曝光：使用浏览记录量，不计算CTR。
- 没有停留时长：使用有记录小时桶，不声称实际在线时长。
- 没有订单/金额：购买记录和跨购买日期是代理，不计算GMV、客单价或真实订单复购。
- 同期商品覆盖率按用户商品对计算，不能当作顺序转化。
- 排名门槛：商品至少50个浏览用户商品对、类目至少200对；按Wilson下界排序。
- 商品四象限只含至少20个浏览用户商品对的11,268件商品；平滑先验权重20、横轴阈值74条浏览、纵轴阈值全局覆盖2.107%。阈值为探索设置。
- 类目区间以用户商品对为观察单位，没有校正同用户聚类与多重选择，仅作描述。
- 小时矩阵允许多行为共存，比较间隔≤24小时的下一观测活跃小时，行和可超过100%；末次记录不视为退出。
- 严格路径要求同用户商品、严格跨小时、首个观测浏览后7天、完整随访；允许同小时的路径只能称候选。
- 历史7天与未来7天严格分开，各截点独立展示，不把多截点同一用户当独立样本合并计算置信区间。
- 31天不足以确定长期季节性；峰值日没有活动日志，暂不作促销归因。
