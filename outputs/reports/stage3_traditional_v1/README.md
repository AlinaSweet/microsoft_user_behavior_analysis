## 使用场景与局限

| 模型 | 本次全量拟合 / 测试预测 | 从实测观察到的取舍 |
|---|---:|---|
| 逻辑回归 | 0.173 / 0.068 秒 | 拟合快，模型可作为轻量线性基线。排序表现落后于两种树模型 |
| XGBoost | 0.901 / 0.107 秒 | 在本次冻结阈值下识别更多正例，适合比较固定触达阈值的召回与 F1 |
| LightGBM | 2.710 / 0.723 秒 | 验证 AUC 和测试排序指标最高，适合以排名为主的候选筛分。当前阈值的召回低于 XGBoost |

同一台 arm64 macOS 主机、4 个原生线程，计时对应最终模型单次拟合和全量概率预测，预测时间从已有特征矩阵开始。CSV 同时记录拟合后进程 RSS。测试正例率约 0.4632%，全预测负例的准确率约 99.54%，因此以 AUC、AP 和召回/F1 解读效果。加权模型在该历史测试上的概率误差可用 Brier 与 Log Loss 对照，实际决策阈值需结合业务约束。
